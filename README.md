# ✨ E-Sparkle Jewelry

A full-stack **jewelry e-commerce platform** with a modern dark-themed UI, user authentication, product management, shopping cart, wishlist, reviews, orders, and an admin dashboard.

## 🚀 Features

* 🔐 JWT Authentication
* 🛍️ Product browsing, search, filters & sorting
* 🛒 Shopping Cart
* ❤️ Wishlist
* ⭐ Product Reviews & Ratings
* 📦 Order Management
* 💳 Checkout
* 👨‍💼 Admin Dashboard
* 📊 Product, User, Order & Review Management

## 🛠️ Tech Stack

**Frontend:** HTML5, CSS3, JavaScript
**Backend:** Node.js, Express.js
**Database:** MongoDB, Mongoose
**Authentication:** JWT, bcryptjs
**Security:** Helmet, CORS, Rate Limiting
**Other:** Nodemailer, Font Awesome

## ⚙️ Setup

```bash
git clone https://github.com/FizzaFaisal07/E-sparkle-MERN.git
cd E-sparkle-MERN

cd backend
npm install
```

Start the backend:

```bash
node server.js
```

Open the frontend using **VS Code Live Server**.
